## 🧑‍💻 About Me

I'm a 23-year-old Computer Science student at the **University of Pannonia** (Veszprém, Hungary) and a working **.NET software developer**.

Instead of just writing theoretical code, I love building things that actually get used—whether that's scalable C# backend architectures, automated Linux server infrastructures, or custom ESP32 hardware setups. When I'm not coding or studying, I mentor high school students for their advanced IT graduation exams in web development.

- 🏗️ **Day-to-day:** Designing C# / .NET backends, REST APIs, and full-stack web apps.
- 🐳 **Infrastructure:** Self-hosting services with Docker, Nginx, and cloud VMs.
- 🔌 **Hardware & IoT:** Building automated microcontroller systems (ESP32, Raspberry Pi) with sensors, relays, and smart home integrations.
- 🎓 **Mentoring:** Teaching native JavaScript, DOM manipulation, and Node.js/Express fundamentals.
